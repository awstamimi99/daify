## Implemented in the working tree

- Bilingual `/admin` workspace: bounded organization/user directories, support
  reasons, audit browsing and reversible status controls. API routes require
  current platform-admin AAL2 access. Status updates serialize, check the expected
  prior state and persist before/after audit data atomically. User disable/restore
  revokes sessions and protects administrator and unverified accounts.
- `/dashboard/analytics`: permitted-location daily totals, date filters,
  zero-state handling, language counts and an accessible data table alongside the
  visual chart. English desktop and Arabic mobile layouts passed browser, accessibility and
  visual verification.
- Local-only anonymous event collection: attribution resolves through published
  menu records. Known bots, prefetch, session-cookie traffic, DNT and GPC are
  excluded. Raw events have no tenant/public read endpoint. Production collection
  remains disabled pending privacy review; the proposed local retention policy
  is in [ANALYTICS.md](../DECISIONS/ANALYTICS.md).
- PostgreSQL event facts, separate processing receipts and daily rollups;
  BullMQ/Redis wakeup, bounded processing, retries and retention. A transaction
  lock plus atomic receipts makes aggregation safe to retry. The additive twelfth
  migration was applied successfully to the disposable database.
- New QR downloads encode `/q/:slug`; redirects resolve current public menu
  aliases. Existing `/r/:slug` links remain supported. QR metrics count route
  visits, not verified physical scans. The browser regression passed, including decoded QR, aliases and rollback.
- An explicit local `analytics:aggregate` CLI permits bounded replay without
  exposing a worker/admin HTTP endpoint.
