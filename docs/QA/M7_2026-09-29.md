## Implemented

- Bilingual `/admin`: bounded organization/user directories, reasoned access,
  audit browsing, reversible suspension and account disable/restore. Platform
  endpoints require current AAL2. Status changes serialize and persist the
  before/after audit atomically; user transitions revoke sessions.
- Admin billing: real plan/subscription directories, immutable sandbox plan
  creation, retirement/reactivation, expiring workspace limits and the nine
  version-controlled template previews. Template entitlements are editable
  through plans/overrides; renderer code remains in source control.
- Restaurant `/dashboard/support` and operator Support tab: bounded plain-text
  conversations, close/reopen, audited operator reads and atomic reply/status,
  audit and in-app notification writes. Notifications are private to the ticket
  creator and organization. The additive thirteenth migration was applied to
  the disposable database. See [the operator handoff](M7_OPERATIONS.md).
- `/dashboard/analytics`: permitted-location daily totals, date filters,
  empty states, languages, chart and accessible daily table. Reports query
  pre-aggregated totals only.
- Anonymous local ingestion with server-owned attribution. Known bots, prefetch,
  previews, session-cookie traffic, DNT and GPC are excluded. Raw events have no
  tenant/public read endpoint. Production collection stays disabled pending
  [privacy approval](../DECISIONS/ANALYTICS.md).
- Immutable event facts, separate processing receipts, daily rollups and bounded
  retention. BullMQ/Redis wakes an idempotent transactional aggregation worker;
  an explicit local CLI supports bounded replay. Migration twelve was verified.
- New QR downloads use `/q/:slug`, then resolve the current public menu. Existing
  `/r/:slug` codes and aliases still work. Counts represent route visits/events,
  not verified physical scans or unique visitors.
